# Heavy Crust Smash Co. | Ultra-Smashed Burgers & Beef Tallow Fries

A production-ready, high-converting showcase website designed for modern fast-casual smash burger concepts, cult street-food spots, and multi-location culinary operations.

## Highlights & Features
- **Visual Aesthetic & Vibe:** Bold, modern industrial diner energy: deep griddle cast-iron charcoal (`#14110e`), warm Dijon mustard gold (`#f59e0b`), fiery sear red (`#ef4444`), warm parchment backdrops (`#FAF8F5`), and dynamic Space Grotesk / Plus Jakarta Sans typography.
- **Interactive "Build Your Custom Smash" Engine:**
  - Real-time patty count selector (Single 3.5oz, Double 7.0oz Lace Edge, Triple 10.5oz Behemoth).
  - Bun choice (Martin's Potato Roll, Brioche, Gluten-Free, Lettuce Wrap).
  - Melted cheese profiles (American, Jalapeño Havarti, Aged White Cheddar).
  - Signature house sauces (Heavy Sauce, Habanero Hot Honey, Truffle Aioli, Griddle Mustard).
  - Premium toppings (Grilled Sweet Onions, Thick-cut Applewood Bacon, Griddle Jalapeños, House Pickles).
  - Instant live price calculator, calorie estimation, and "Add To Bag" confirmation flow.
- **Interactive Menu Browser:** Filterable menu tabs across Signature Burgers, Beef Tallow Sides, Hand-Spun Custard Shakes, and Local Craft Sodas.
- **The Science of the Sear Bento Grid:** Educational interactive cards showcasing:
  - 650°F Chromium griddles generating Maillard lace-edge crisp.
  - 100% Meyer Ranch Wagyu brisket & chuck blend.
  - Twice-cooked hand-cut fries crisped exclusively in pure beef tallow.
  - Real Pennsylvania Dutch frozen custard hand-spun to order.
- **Live Location Status & Hours Tracker:** Active badges for Downtown Mission, Marina District, and Oakland locations with wait-time indicators and direct delivery links.
- **Quick-Order & Catering Booking Modal:** Friction-free pickup/catering inquiry modal with iOS-safe form inputs (preventing auto-zoom) and background scroll locks.
- **Tech Stack:**
  - Semantic HTML5
  - Tailwind CSS via CDN
  - Lucide Icons
  - Google Fonts (Space Grotesk & Plus Jakarta Sans)
  - 100% Mobile Responsive with zero build-step dependencies

## Setup & Deployment
Open `index.html` directly in any web browser or deploy immediately to GitHub Pages, Netlify, or Vercel:

```bash
# Push to GitHub
git remote add origin https://github.com/YOUR_USERNAME/heavy-crust-smash-burgers.git
git branch -M main
git push -u origin main
```
